## Why Asset Inventory Comes First

Security teams need to know what systems they are protecting before vulnerabilities, incidents, and risk can be assessed.

Each later security record is linked to an asset so analysts can understand which system is affected and how important it is.

## Why IP Addresses Must Be Unique

A duplicate IP address could create confusion during investigation and cause activity to be linked to the wrong asset.

The database therefore blocks duplicate IP addresses to maintain reliable asset identification.

## Why Asset Criticality Is Stored

Not every system has the same business impact.

Critical systems such as database servers and VPN gateways require faster attention than standard user devices when vulnerabilities or incidents are detected.
